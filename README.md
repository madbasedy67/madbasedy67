<h3 align="center">Powered by curiosity (and too much coffee).</h3>

I'm a data analyst who spends most days turning half-broken spreadsheets into tables I can actually trust. Most of what I build lives in Python — Pandas and NumPy for the messy cleaning, DuckDB and SQL when the data outgrows my laptop's RAM, and Jupyter when I need to think out loud for a while. Lately I've been pulled toward the plumbing side of things, ETL pipelines and data engineering, because a dashboard is only as good as whatever feeds it.

#### What I do

- 🔭 Rebuilding my messy CSVs into a DuckDB-backed pipeline that runs on schedule.
- 🌍 Based in Singapore
- 🤔 Thinking about data engineering
- 📚 Currently reading whatever the docs link to
- 🌱 Learning SQL
